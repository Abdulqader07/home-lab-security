# Unbound DNS

**Role:** Recursive DNS resolver with forwarding.
**Host:** Rocky Linux Server (192.168.20.2)
**Port:** UDP/TCP 53

## Config

```
/etc/unbound/unbound.conf
```

| Key | Value |
|---|---|
| interface | 0.0.0.0, ::0 |
| access-control | 192.168.20.0/24, 192.168.30.0/24 |
| forward-addr | 1.1.1.1, 8.8.8.8 |
| local-data | mail.lab.local A 192.168.20.3 |
| local-data | lab.local MX 10 mail.lab.local. |

## Prerequisite

```bash
sudo mkdir -p /var/log/unbound
sudo chown unbound:unbound /var/log/unbound
sudo chmod 755 /var/log/unbound
```

## Firewall 

```bash
sudo firewall-cmd --permanent --add-service=dns
sudo firewall-cmd --reload
```

## Enable 

```bash
sudo systemctl enable --now unbound
```

## Verify

```bash
dig mail.lab.local @192.168.20.2
```
