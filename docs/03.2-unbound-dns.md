# Unbound DNS

**Role:** Recursive DNS resolver with forwarding.
**Host:** Rocky Linux Server (192.168.20.2)
**Port:** UDP/TCP 53

## Config

/etc/unbound/unbound.conf

| Key | Value |
|---|---|
| interface | 0.0.0.0, ::0 |
| access-control | 192.168.20.0/24, 192.168.30.0/24 |
| forward-addr | 1.1.1.1, 8.8.8.8 |
| local-data | mail.lab.local A 192.168.20.3 |
| local-data | lab.local MX 10 mail.lab.local. |
