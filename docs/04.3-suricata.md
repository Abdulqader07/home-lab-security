# Suricata IDS

**Role:** Inline intrusion detection on the sensor.
**Interfaces monitored:** enp0s8 (intnet), enp0s9 (srvnet), enp0s10 (idsnet).
**Log:** /var/log/suricata/fast.log

## Config

/etc/suricata/suricata.yaml - af-packet section:

```yaml
af-packet:
  - interface: enp0s8
    cluster-id: 99
    cluster-type: cluster_flow
    defrag: yes
  - interface: enp0s9
    cluster-id: 98
    cluster-type: cluster_flow
    defrag: yes
  - interface: enp0s10
    cluster-id: 97
    cluster-type: cluster_flow
    defrag: yes
```

## Custom Rules

/etc/suricata/rules/local.rules:

```bash
alert tcp any any -> 192.168.20.0/24 25 (msg:"SMTP from outside servers farm"; sid:1000001; rev:1;)
alert tcp any any -> 192.168.20.0/24 22 (msg:"SSH from outside servers farm"; sid:1000002; rev:1;)
alert tcp any any -> 192.168.20.0/24 389 (msg:"LDAP from outside servers farm"; sid:1000003; rev:1;)
alert tcp any any -> 192.168.20.0/24 143 (msg:"IMAP from outside servers farm"; sid:1000004; rev:1;)
alert icmp any any -> 192.168.20.0/24 any (msg:"ICMP to servers farm"; sid:1000005; rev:1;)
```

These fire on any cross-zone access to sensitive services.

## Enable

```bash
sudo suricata-update
sudo suricata -T -c /etc/suricata/suricata.yaml
sudo systemctl enable --now suricata
```

## Test

From Kali:

```bash
nmap -sS 192.168.20.3
nc -zv 192.168.20.2 22
nc -zv 192.168.20.2 389
nc -zv 192.168.20.3 25
ping -c 3 192.168.20.3
```
Check on sensor:

```bash
sudo tail -f /var/log/suricata/fast.log
```
Expected: alerts for each probe above.

## Alert Format

```bash
[**] [1:1000001:1] SMTP from outside servers farm [**]
[Classification: (null)] [Priority: 3]
{TCP} 192.168.30.6:49500 -> 192.168.20.3:25
```

Source 192.168.30.x = Kali (intnet).
Destination 192.168.20.x = servers farm (srvnet).

Gotchas

- YAML is strict about indentation — use spaces, not tabs

- Rules must be listed under rule-files: in suricata.yaml

- Restart Suricata after any rule change
