# Kea DHCP

**Role:** Assign IP addresses to intnet clients.
**Host:** Rocky Linux Server (192.168.20.2)
**Port:** UDP 67

## Config

`/etc/kea/kea-dhcp4.conf`

| Key | Value |
|---|---|
| interface | enp0s8 |
| valid-lifetime | 3600 s |
| subnet | 192.168.30.0/24 |
| pool | 192.168.30.2 - 192.168.30.10 |
| default gateway | 192.168.30.1 |
| DNS | 192.168.20.2 |

## Firewall

```bash
sudo firewall-cmd --permanent --add-service=dhcp
sudo firewall-cmd --reload
